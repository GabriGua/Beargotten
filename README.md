# Beargotten

A Unity game project.

## About

Beargotten is a Unity-based game project built with Unity 2022.3.10f1.

## Project Structure

- **Assets/Scenes/** - Game scenes
  - MainScene.unity - Main game scene
- **Assets/Scripts/** - C# game scripts
  - GameManager.cs - Core game manager singleton
  - PlayerController.cs - First-person player controller
- **Assets/Prefabs/** - Reusable game objects
- **Assets/Materials/** - Materials and shaders
- **Assets/Textures/** - Texture assets

## Getting Started

### Prerequisites

- Unity 2022.3.10f1 or later
- A compatible IDE (Visual Studio, VS Code, or Rider)

### Opening the Project

1. Clone this repository
2. Open Unity Hub
3. Click "Add" and navigate to the project folder
4. Open the project with Unity 2022.3.10f1 or later
5. Open the MainScene from Assets/Scenes/

### Controls

- **WASD** - Move
- **Mouse** - Look around
- **Space** - Jump
- **Escape** - Unlock cursor

## Development

This project uses Unity's standard project structure. All game code is written in C# and located in the Assets/Scripts folder.
